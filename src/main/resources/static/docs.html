Descrição geral
  • Especificação: OpenAPI 3 (documentação gerada com Swagger UI).
  • Codificação: UTF-8. Envie e receba JSON em UTF-8 (acentos e caracteres especiais são aceitos).
  • Idioma: português do Brasil. A documentação e as mensagens de erro estão em pt-BR; os textos cadastrados (nomes, títulos) podem estar em qualquer idioma.
  • Formato: JSON. Nomes de campos e valores do formato do disco (VINIL, CD, FITA_K7, DIGITAL) devem ser enviados exatamente como na documentação.
  • Paginação: toda listagem é paginada. A primeira página é a 0 (?page=0), o tamanho padrão é 10 e o máximo é 50 itens por página (?size=50).
  • Dados inválidos não são cadastrados: campo vazio, texto acima do limite ou número fora da faixa retorna erro 400.
  • HATEOAS: as respostas trazem _links para navegar entre os recursos.

Termos de serviço

Quem usa esta API deve:

  • enviar dados verdadeiros e dentro dos limites, para manter a coleção consistente;
  • cadastrar artistas, gêneros e capas antes de ligá-los a um disco, porque os ids informados precisam existir;
  • excluir primeiro o que depende de um registro (ex.: discos de um artista) antes de excluí-lo.
